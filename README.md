# Project U

The website for Project Unbounded, an AI implementation consultancy. Its scroll-led forest walk and minimal copy introduce the work.

## Preview locally

```sh
python3 -m http.server 8000 --directory dist
```

Open `http://localhost:8000`. This is a static site with no build step. The deployment configuration is in `.openai/hosting.json`. Bundled font licenses are in `dist/fonts/`.
